# 🎯 Bubble Game

Welcome to **Bubble Game** — a fun and interactive JavaScript-based browser game where you test your reflexes and aim by clicking the correct bubble before time runs out! ⏱️💥

---

## 🕹️ How to Play

- You'll see **bubbles with numbers** appear on the screen.
- At the top, you'll be shown a number to **"Hit"**.
- Click on the **bubble that matches** the hit number.
- Each correct hit = 🎯 **+10 points**!
- You have **60 seconds** to score as much as you can.
